# 变更日志

## [3.5.0] - 2026-05-12

### 新增
- **项目蓝图文档** (`docs/BLUEPRINT.md`) — 完整的项目架构、数据流、部署说明
- **调试日志系统** (`src/utils/debugLogger.ts`) — 分级日志（debug/info/warn/error）、模块标记、持久化存储
- **调试面板** (`src/admin/components/DebugPanel.tsx`) — 设置页可查看实时日志，支持过滤/搜索/导出
- **批量导入 Markdown** (`src/admin/components/BatchImportModal.tsx`) — 支持多文件选择、文件夹拖拽、YAML frontmatter 解析、预览、状态选择

### 改进
- PostList 页面增加「批量导入」入口按钮
- Settings 页面集成调试日志面板
- readTime 计算改用中文字符计数（300字/分钟）
